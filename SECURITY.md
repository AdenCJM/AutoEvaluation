# Security policy

## Reporting a vulnerability

Do not disclose API keys, prompt content, generated outputs, exploit details, or vulnerabilities in a public issue. Report them privately through the contact method on the GitHub profile for AdenCJM.

## Safe operation

AutoEvaluation can make paid provider calls and writes campaign artefacts locally. Keep secrets in environment files, review generated configuration before use, and do not commit campaign data unless it is intentionally redacted and shareable.
